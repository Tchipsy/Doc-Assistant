# 文档整理公共提示词（按源类型选择其中一个小节）

> 约定：`## <小节名>` 为加载器识别的小节；小节名不可改动。
> `## 文档` 适用于本地文档类源（教材/课件/试卷/书籍等 PDF 或 markdown，输入带页码标记）；
> `## 网页` 适用于网页类源（爬取的网页正文）。pass1 组装系统提示词时按整理预设的分组（文档/网页）只挂载其中一个小节，预设自身不再重复这些规则。

## 文档

【文档类公共规则（所有文档类整理预设共用，与预设自身规则共同生效）】
1. 翻译与纠错：全文整理为简体中文；专业术语与核心概念（定义、定理、方法、组件等名称）在其后括号标注英文原词，如：冲突可串行化（conflict serializability）。OCR 识别错误、乱码、缺漏直接按正确内容纠正（基于上下文与专业常识），不要在文中说明——例如明显的识别错误"用SOL语句"应纠正为"用SQL语句"。数学公式保持 LaTeX 原样（$...$ / $$...$$）。
2. 排版：保留原文的排版结构（列表、表格、公式、代码块的层级与语义）；必须原样保留所有 <img src="..."> 图片标签（含 src/alt/width 等全部属性），不得删除、不得替换为纯文字说明；可在图片下方保留图注。
3. 页码标注：输入中的 <!-- page:N --> 标记是页码唯一来源，禁止虚构。每个二级（##）与三级（###）标题末尾用括号标注该节覆盖的原文页码范围，如：## 主题（p.5）或 ### 小节（p.5–7）；页码范围取该节内容中出现的页标记的最小–最大值。四级及更深的标题不标页码。
4. 页标记保留：<!-- page:N --> 标记必须原样保留在输出正文的对应内容处（系统依赖它做进度定位），一行一个，位置对应整理后的相应内容。

【网页类公共规则（所有网页类整理预设共用，与预设自身规则共同生效）】
任务背景：输入通常是从网页抓取的正文（已剥离页面框架，但可能残留导航、广告、脚本痕迹与转换噪声），目标是把不易读的网页内容转成结构直观、可长期阅读的 markdown 资料文档。
1. 去噪：剔除与正文无关的残留——站点导航、面包屑、广告与推广位、相关推荐、登录/订阅/cookie 提示、点赞收藏按钮、脚本与样式残留文本；重复出现的页眉页脚只保留一次或全部去除。
2. 语义结构：按正文自身的语义组织标题层级——大主题用二级标题（##），子主题用三级（###），更细用四级（####）；禁止输出一级标题（#，文档标题由系统处理）；网页里为排版而设的装饰性标题不作为层级依据。
3. 表格：HTML 表格转换为 markdown 表格，保持行列对应关系；单元格内多段内容压缩为一行（可用 <br> 分隔）；过宽或深层嵌套的表格可改写为列表，但不得丢失对应语义。
4. 图片：正文中的 <img src="..."> 标签原样保留（含 src/alt 等全部属性）并保留图注；表情图、装饰图标、二维码等非内容图片直接删除。
5. 链接：正文中承担语义的关键链接保留为 [文字](URL)（如引用来源、词条、下载地址）；导航类链接剔除；原文的参考链接列表保留为文末小节。
6. 语言与净化：全文整理为简体中文（原文为外语时翻译，专有名词括号标注原词）；解码 HTML 实体（&amp;、&#xNN; 等）并修复转码乱码；代码保持原语言并使用 ``` 围栏，行内代码用反引号。
