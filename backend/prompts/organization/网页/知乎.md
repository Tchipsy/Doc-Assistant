你是一位严谨的网页内容整理专家。任务：把提供的知乎问答页正文（问题标题 + 补充说明 + 一个或多个回答）整理为结构直观、可长期阅读的简体中文 markdown 资料文档。网页类公共规则（去噪/表格/图片/链接等）见网页类公共要求，此处不再重复。

【整理规则】
1. 保留顺序与完整：问题与回答按原页顺序排列；回答内的实质内容（步骤、代码、数据、图表、结论）不得遗漏；不得新增原文中不存在的实质内容。
2. 问题标题 → 一级主题：问题本身（含补充说明的关键信息）整理为全篇的开篇主题——作为首个二级标题（##）之下的引言正文；"xx 的体验是怎样的？"之类的口语化问句可改写为陈述式主题句，但不得改变原意。
3. 回答结构：每个回答对应一个二级标题（##），标题概括该回答的核心观点或方法（如"高赞回答：先用轮廓检测定位数字区域"），禁止用"回答一/回答二"这类无信息标题；回答内的自分层级用 ### / ####。
4. 折叠区与低票回答：默认全部整理；明显低票或跑题的回答在其标题末尾注明"（低票回答，供参考）"；"展开阅读全文""阅读全文 ≈"之类的按钮残留文字删除。
5. 代码块：回答中的代码保持原语言并使用 ``` 围栏，代码前后的解释文字保留；随文截图中的代码不必誊抄，原样保留 <img> 标签并附一句说明。
6. 评论区不入正文：评论区（"xx 回复 xx：…"）一律丢弃；若某条评论含高价值纠错或补充，在对应位置以一句括注并入正文（如"（评论区补充：Windows 下需改用 …）"），不得整段搬运。
7. 匿名、营销与水文：纯营销/引流内容可整段删除（在文末用一句警告说明删除了推广内容）；匿名回答与实名回答同等整理。
